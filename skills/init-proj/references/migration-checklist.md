# 迁移与验收清单

## 输入与盘点

- 仓库、目标工具、模式、写入范围和外部依赖已明确。未提交变化记录在案，既有文件均先读取。
- 发现包括隐藏/忽略文件、嵌套入口、符号链接、已有技能/角色/hooks/settings，不只看根目录。
- 记录旧文件完整内容的行数/内容标识；大文件分段读取，拒绝截断内容参与重写。
- 本机权限不输出凭据值，不整目录解除忽略。
- 涉及任务资料时读取[任务生命周期](todo-lifecycle.md)与项目约定，盘点当前task/完成归档/历史证据类别及引用；无需求不创建空目录，不全量加载无关历史。

## 迁移执行

1. 分类正文与适配，列出独有要求、重复段与冲突。
2. 对每个旧文件建立对应新位置或明确保留理由；语义变化另行确认。
3. 创建目标文件后，核对独有要求、规则ID、证据、角色边界均保留。
4. 重算相对路径；更新当前导航、允许的本仓引用，历史证据不机械替换。
5. 检查root AGENTS/CLAUDE链接与导入环；在不支持链接的环境采用薄入口而非副本。
6. 外部依赖尚未更新时旧路径留短迁移说明；不得先删旧文件后发现内容丢失。
7. 仅精确放行已审查工具文件，新增本机配置保持忽略。
8. 清理旧文件前核对绝对路径；新正文验收前不删除来源。

## 验收（须实跑）

- 内容：旧→新每个独有要求有去处，规则被废止时明确原因；角色只拆正文与工具元数据。
- 结构：仅共享目录维护正文；工具目录仅薄适配和专有配置；已有skills/hooks不变。
- 链接：相对目标从所在文件算，文件/目录存在；锚点可达；没有自引用导入或循环链接。
- 检查器：构造不存在的链接/循环导入等已知坏输入，确认恰好预期失败，不仅“看起来没报错”；运行后移除探针。
- Markdown：frontmatter name/description格式可解析；任务按项目约定核对name/desc/created/updated/status，done另有completed；模板中的例子不被工具误认成实际指令入口。
- 任务：name与文件名一致、命名/日期合法、未重复；todo未完成、完成验收后移动原文件保留名称，未留复制副本；blocked/延期/取消不误标done，历史证据单独标类别且不设done。
- 归档：检查目标重名/符号链接，重算内部路径及所有当前引用/锚点，同步索引与完成日期CHANGELOG摘要；历史含义、事故/独有约束/回滚保留，不为压缩复制凭据。
- 密度：活动任务仅目标/当前结论/下一步/验收/必要回滚，资产不重复过程，CHANGELOG每日通常1–3条；原始日志不入共享正文，历史仅按需读。重复执行不新建快照或为形式再迁移。
- Git：`git diff --check`；未跟踪的新文件也检查空白，不能只查tracked diff。`git check-ignore -v`分别验共享和本机配置，预期未命中时exit 1不是异常。
- 隔离：共享内容不含个人绝对路径、凭据或历史宽权限；不要将示例占位符漏进已落地入口。
- 幂等性：已符合结构时再执行audit不应提出无理由迁移，第二次apply不生成重复正文、不覆盖用户更新。
- 工具：在目标版本新会话中验证入口/roles/skills发现；若无法执行，明确报告“布局验证通过、工具加载未验证”。
- 变更范围：不改业务、不运行发布、不改其他仓库或知识库正文，除非分别授权。

## 测试场景

| 场景 | 应有行为 |
|---|---|
| 全新项目、工具未知 | audit并询问必要信息；不虚构构建命令或六人团队 |
| 根入口+隐藏入口重复，隐藏有独有记忆规则 | 提取独有规则、迁移导航，不直接删除 |
| AGENTS是CLAUDE符号链接 | 导入前阻止循环；先核对目标再调整 |
| .claude整体忽略且含settings.local凭据 | 白名单共享文件；本机授权不变、不进Git |
| 大文档超过read默认范围 | 分段读取并核对行数，不能截断写回 |
| 已有skills和hooks | 原样保留，用户未授权不覆盖 |
| docs中业务设计与agent说明混放 | 只迁移agent专用正文，工程文档仍留docs |
| 同一布局重复执行 | audit稳定，apply零无理由diff |
| 无任务管理需求 | 不生成todos/archive/任务规则或空任务 |
| 同一任务跨日或重试 | 更新原文件，不改创建日期/文件名、不建重复任务 |
| done仍留todos或任务未验收 | 拒绝done留活动目录；未完成不因文档整理归档 |
| archive混放完成任务和历史快照 | 索引分别分类；快照不使用status: done，不冒充完成 |
| 任务归档后内部/外部引用失效 | 修正路径与锚点、同步索引/CHANGELOG，不假定链接追踪移动 |
| 活动任务与资产反复追加长过程 | 必要历史保留验证后压缩，不丢独有回滚、不再逐轮建快照 |
| 原任务取消或归档目标已存在 | 记录决定、先核验目标与符号链接；不伪装done、不覆盖 |

## 交付格式

结论 / 新布局与职责 / 迁移映射 / 已处理冲突 / 实跑验证 / 未验证和外部缺口 / 工作树及提交状态。不要用“已初始化”掩盖尚未跟踪或工具未加载。
