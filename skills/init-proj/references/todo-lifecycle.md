# 任务生命周期与历史归档

## 适用与按需接入

处理项目任务记录、todo布局、完成归档或长文档压缩时，实际读取本参考及项目现有规则。沿用既有目录、字段和工作流；规则冲突先说明，不为统一外观批量搬迁。

无现有约定且确有任务管理需要时，可采用：

```text
notes/
├── README.md       # 活动任务、完成任务、历史证据三类索引
├── todos/          # 未完成任务的当前可执行状态
└── archive/        # 已验收任务或明确分类的历史证据
```

这些是人和Agent共用的项目资料，不移入`.agents`。只有需要建立跨工具约束时，才在`.agents/rules/todo-lifecycle.md`维护项目规则，并由AGENTS明确要求相关任务执行前实际读取；普通链接不等于自动加载。

最小init不默认创建上述目录、索引、规则或空任务。新增内容须有真实用途，并符合init/migrate的授权范围；文档规则不是操作授权、hook或自动门禁。

## 职责与创建

- todos保存目标、当前状态和下一步；archive不是逐轮日志仓库。
- 索引分别列活动任务、完成任务和历史证据；资产/设计文档维护当前事实，不复制任务过程。
- 每个有独立目标、验收或排期的任务建一份文件，实施前先明确范围和验收。不要为每条命令或每次尝试建任务，也不要求每次微小问答都建记录。
- 默认命名`YYYYMMDD-kebab-case.md`，日期为创建日期。继续同一任务更新原文件，不因跨日、重试或下一轮诊断改名/另建。
- 重名先判断是否同一任务；独立任务可用`-02`、`-03`，不得覆盖已有文件。拆分确有独立验收的工作时，在原任务链接去向，不丢未完成项。

## 最小内容与状态

无现有字段约定时，新任务采用：

```yaml
---
name: 20261012-example-task
desc: 短说明
created: 2026-10-12
updated: 2026-10-12
status: pending
---
```

`name`与文件名去扩展名一致；实际填写时替换示例，日期使用`YYYY-MM-DD`。本任务字段`desc`不改变SKILL或角色自身的frontmatter规范。

| 状态 | 含义 |
|---|---|
| pending | 尚未开始，计划不等于实施 |
| in_progress | 正在推进，部分完成不等于全范围完成 |
| blocked | 关键前置受阻，说明阻塞及解除条件 |
| done | 任务范围内验收全部完成 |

正文仅保留：

1. 目标、范围、不做事项与授权边界。
2. 当前结论、必要证据来源/日期及未核验项；区分实测、历史、建议和已实施。
3. 下一步与可核验的验收清单；记录失败/跳过/延期，不用文档完成替代业务验收。
4. 涉及变更时的真实依赖、管理通道、备份和必要回滚；无授权不执行，文档方案不代替授权。

## 完成与归档

- 仅验收全部完成才标done，补`completed`日期及实际验证结果。
- 将原文件移动到archive，保留文件名，不复制一份留todos。仍待授权、受阻、延期或有未完成验收的任务留todos，使用对应状态。
- 用户取消时记录决定和原因，不冒充done；是否及如何归档按用户决定，不擅自引入新状态。
- 移动前检查来源、目标、重名和符号链接，不覆盖现有归档。移动后重算文件内部相对链接，并更新所有当前入口、资产、任务间引用与锚点；链接不会自动追踪移动。
- 同步索引和CHANGELOG：用实际完成日期，通常每日1–3条任务/结果/验证/归档链接摘要。进行中、纯文档迁移或部分验收不得写成业务完成。

## 历史证据不是完成任务

- 快照可放archive，但明确标注如`category: historical_evidence`，不设`status: done`，并在索引单独分类。
- 保留当时语境；旧“当前配置/待办”不是最新事实或操作指令。不为修旧链接改写历史含义；必要时添加背景说明。
- 压缩已有长文前，先检查敏感信息，保留并验证必要历史/完整来源；事故、独有约束与回滚信息不得丢失。无敏感源可用行数/指纹验证内容保留；不得为保持指纹而复制凭据。
- 只在有追溯价值时建立快照，不每轮追加/新建。历史按需读取，不导入默认开工上下文；未完成任务仍留精简todos，不能伪装归档完成。

## 记录密度

- 更新结论，不不断追加过程。原始日志、完整时序、命令输出、重试和重复状态留会话临时证据，不自动成为共享记录。
- 仅改变决策、当前事实、验收或回滚的内容值得简短记录；结论应有足够证据与限制，但不复制整份配置或采样结果。
- todo保存工作状态，资产保存当前事实，索引保存导航，CHANGELOG保存摘要；同一证据只维护一个详细来源，其他位置链接。
- 活动文档过长先去重、合并旧结论，必要时一次性保留历史再压缩；不能靠持续拆档、逐轮快照转移膨胀。不为行数删掉独有约束或必要回滚。
- 凭据、个人权限和秘密不进入todo/归档；只留安全来源引用。临时证据不能当已验收的长期备份。

## 验收与交付

检查命名/frontmatter/日期、task状态与位置、无重复任务、归档类别、相对链接/锚点、证据与回滚保留、索引/CHANGELOG同步和敏感信息隔离；取消/未核验不误标完成。

检查器用已知坏输入证明会失败，例如done仍留todos、历史快照误设done、不存在链接或归档移动后失效引用；测试后清理探针。重复执行不产生重复正文或快照，不改用户后续更新。

纯文档验证不启动真实服务；报告实际检查、未验证项和写入/保留文件。普通导航/静态检查不证明工具自动加载，默认不提交、发布或部署。
